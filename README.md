# Лабораторная работа №5. Знакомство с базами данных Python и SQLite

**Вариант:** 27  
**Тема:** Читательские марафоны

## Описание полей таблицы `marathons`
* `id` (`INTEGER PRIMARY KEY`) — уникальный номер записи.
* `name` (`TEXT`) — название читательского марафона.
* `category` (`TEXT`) — жанр.
* `value` (`INTEGER`) — плановое количество страниц.

## Запуск программы
```bash
python main.py
```

## Выполненные операции
1. Создание базы данных `app.db` и таблицы `marathons`.
2. Добавление 8 исходных записей по трём жанрам («Фантастика», «Детектив», «Классика»).
3. Вывод всех записей (`SELECT *`).
4. Отбор записей категории «Фантастика» (`WHERE category = 'Фантастика'`).
5. Фильтрация записей со значением больше 200 (`WHERE value > 200`).
6. Сортировка записей по возрастанию количества страниц (`ORDER BY value ASC`).
7. Изменение значения `value` у записи с `id = 2` (`UPDATE`).
8. Удаление записи с `id = 8` (`DELETE`) и вывод оставшихся записей.
